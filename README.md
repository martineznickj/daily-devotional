# Daily Devotional — The Seven Moves

A calm, modern daily Bible devotional, read through the **Seven Moves** (the modern Trivium + Quadrivium):

**Gather** · **Filter** · **Deliver** · **Count** · **Shape** · **Flow** · **Zoom**

Each day is one theme and one move. Scripture is quoted from the **ESV**.

## How it works

- `index.html` — the whole site (single page, dark mode, archive).
- `devotionals.json` — the content. One entry per day, newest first.
- A scheduled job appends today's entry each morning and pushes it here.
